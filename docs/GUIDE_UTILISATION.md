# Guide d'utilisation — Dashboard Direction CSIG

Guide pratique au quotidien. Chaque section répond à une action concrète :
« je veux faire X, comment je fais ? ».

---

## 1. Premiers pas

| Action | Comment |
|---|---|
| **Me connecter** | Adresse de la plateforme → identifiant + mot de passe → **Se connecter** |
| **Mot de passe oublié** | Lien « Mot de passe oublié » sur la page de connexion → suivre l'email |
| **Changer mon mot de passe** | Avatar (haut à droite) → **Mon compte** → **Changer le mot de passe** |
| **Modifier mes infos** | Avatar → **Mon compte** → téléphone, photo |
| **Me déconnecter** | Avatar → **Se déconnecter** |

> Sur un poste partagé, toujours se déconnecter.

---

## 2. Le menu en un coup d'œil

Le menu latéral s'adapte à votre **rôle**. Voici ce que vous trouvez (ou non) :

| Section | Je m'en sers pour… | Visible si… |
|---|---|---|
| **Tableau de bord** | Vue d'ensemble rapide (KPIs) | Tout le monde |
| **Projets** | Suivre/créer les projets | Gestion projet, direction, DG |
| **Mes tâches** | Mes jalons et sous-étapes | Compte relié à un employé |
| **Calendrier** | Réunions et événements | Tout le monde |
| **Congés** | Mes demandes + validations | Tout le monde (+ validations selon rôle) |
| **Ressources** | Budgets et employés | Gestion budgets |
| **Demandes** | Valider les demandes | Approbateurs (directeurs/DG) |
| **Documents** | Fichiers de l'organisation | Lecture/gestion docs |
| **Partenaires** | Base des partenariats | Lecture partenaires |
| **Rapports** | Exports PDF | Lecture rapports |
| **Utilisateurs / Directions / Rôles** | Administration | Admin / DG |

**Règle simple** : si une section ou un bouton n'apparaît pas, c'est que votre
rôle n'y a pas accès.

---

## 3. Tableau de bord — je clique quoi ?

Les cartes sont **cliquables** :

- **Mes projets** → liste des projets.
- **Mes tâches** → mes jalons/sous-étapes.
- **Mes congés** → mes demandes.
- **Budget consommé** → ressources.
- **Partenaires actifs** → partenaires.
- **Projets en cours** → projets de ma direction.

---

## 4. Projets — actions courantes

| Je veux… | Je fais… |
|---|---|
| **Voir un projet** | **Projets** → cliquer sur le projet |
| **Créer un projet** | **Projets** → **Nouveau projet** (nom, priorité, statut) |
| **Ajouter un jalon** | Fiche projet → **Jalons** → **Ajouter un jalon** (nom, date, responsables) |
| **Faire avancer un jalon** | Fiche jalon → changer le **statut** : à faire → en cours → en révision → terminé (ou **bloqué**) |
| **Découper en sous-étapes** | Fiche jalon → **Sous-étapes** → ajouter/assigner |
| **Ajouter un membre** | Fiche projet → **Membres** → **Ajouter** + choisir le **rôle projet** |
| **Déposer un document projet** | Fiche projet → **Documents** → **Nouveau document** |
| **Commenter** | Fiche projet → zone **Commentaires** |

> Le statut **bloqué** sert à signaler un problème : les participants sont
> notifiés en temps réel.

---

## 5. Mes tâches — au quotidien

1. **Mes tâches** liste les jalons/sous-étapes dont je suis responsable.
2. J'ouvre la tâche, je mets à jour :
   - le **statut** (à faire → en cours → … → terminé),
   - la **progression** (%),
   - la **date** si elle change.
3. Chaque changement notifie les autres participants.

---

## 6. Calendrier — organiser une réunion

1. **Calendrier** → **Nouveau** (ou cliquer sur une date).
2. Type **Réunion** ou **Événement** → titre, date, heure, durée, lieu.
3. Choisir les **directions** invitées → enregistrer.
4. Depuis la fiche, répondre (RSVP) ou suivre les réponses.

---

## 7. Congés — le workflow en 4 étapes

```
1. Je soumets  →  2. Mon manager donne son avis  →  3. La RH vérifie  →  4. Décision finale
```

### Employé : demander un congé
1. **Congés** → **Nouvelle demande**.
2. Dates début/fin, type, motif, justificatif éventuel.
3. **Soumettre**.
4. Suivre dans **Congés** : en attente / approuvée / rejetée.
5. Une fois approuvée : **télécharger l'attestation PDF**.

> Tant que c'est « soumise », je peux modifier ou annuler. Après validation,
> c'est verrouillé.

### Manager : donner un avis
1. **Congés** → liste des demandes à traiter (statut **soumise**).
2. Ouvrir la demande → **Avis favorable** / **Défavorable**.

### RH : vérifier la conformité
1. Demande au statut **avis favorable**.
2. **Conforme RH** / **Non conforme**.

### Décideur : décision finale
1. Demande au statut **conforme RH**.
2. **Approuver** / **Rejeter** → l'employé est notifié + un email part.

## 8. Documents

| Je veux… | Je fais… |
|---|---|
| **Déposer un fichier** | **Documents** → **Nouveau document** → choisir le fichier |
| **Lire sans télécharger** | Bouton **Aperçu** |
| **Récupérer un fichier** | Bouton **Télécharger** |
| **Faire valider/signer** | Boutons **Valider** / **Signer** (selon droits et workflow) |

> Nommez les fichiers clairement avant l'envoi : le nom s'affiche tel quel au

---

## 9. Demandes (approbateurs)

1. **Demandes** répertorie les besoins soumis.
2. Ouvrir une demande → **Approuver** ou **Rejeter**.
3. Le demandeur est notifié + reçoit un email.

## 10. Budgets et ressources

| Je veux… | Je fais… |
|---|---|
| **Voir les budgets** | **Ressources** → budgets par projet/direction (alloué, consommé, reste) |
| **Créer un budget** | **Ressources** → **Nouveau budget** (montant, projet/direction) |

## 12. Rapports

| Je veux… | Je fais… |
|---|---|
| **Exporter l'activité** | **Rapports** → **Rapport général / Employés** → **Exporter PDF** |
| **Exporter un projet** | Fiche projet → **Activités → Export** (PDF) |

Le fichier PDF téléchargé est prêt à partager.

---

## 13. Notifications — ne rien manquer

- **Cloche** (haut à droite) : nombre de non-lues + menu des notifications.
- Cliquer une notification → la ressource concernée.
- **Voir toutes les notifications** → historique.
- Vous êtes notifié pour : affectation de tâche, changement de statut,
  commentaire, décision congé/demande, invitation, compte créé.

## 14. Administration (admin / DG uniquement)

| Je veux… | Je fais… |
|---|---|
| **Créer un compte** | **Utilisateurs** → **Nouveau** → l'utilisateur reçoit un lien d'activation |
| **Relancer une invitation** | **Utilisateurs** → **Renvoyer l'invitation** |
| **Désactiver un compte** | **Utilisateurs** → modifier → **désactiver** (ne pas supprimer) |
| **Réinitialiser un mot de passe** | **Utilisateurs** → compte → **Mot de passe** |
| **Voir l'activité** | **Utilisateurs** → **Activités** |
| **Créer une direction** | **Directions** → **Nouveau** (nom, code, couleur) |
| **Gérer les rôles** | **Rôles** / **Rôles projet** → combiner action × sujet × condition |

---

## 15. Problèmes fréquents

| Problème | Solution |
|---|---|
| Je ne vois pas une section | Elle dépend de mon rôle → contacter l'admin si besoin |
| Email d'activation absent | Chercher dans les courriers indésirables → demander « Renvoyer l'invitation » |
| Notification temps réel absente | Vérifier la connexion, recharger la page |
| Congé non modifiable | Il est déjà validé → en faire un nouveau |
| Fichier au mauvais nom au téléchargement | Renommer le fichier avant l'upload |
| Accès partenaire | L'admin crée le compte + rôle projet « Ressource externe » |
